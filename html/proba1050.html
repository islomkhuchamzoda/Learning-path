БЕЗОПАСНЫЙ ОБМЕН БЕЗ СТАТИЧЕСКОГО IP

1C Agent Pro обеспечивает обмен данными между 1С и мобильными устройствами агентов без необходимости подключения статического IP-адреса. Данные передаются по зашифрованному соединению.

БАЛАНСИРОВКА НАГРУЗКИ И МАСШТАБИРОВАНИЕ

Распределение нагрузки и параллельная обработка запросов агентов в 1С позволяют масштабировать 1C Agent Pro по мере роста компании, количества сотрудников и объёма передаваемых данных.

УСТАНОВКА НА СВОЁМ СЕРВЕРЕ

Возможна установка серверного модуля на собственный сервер компании. Статический (белый) IP-адрес не требуется — работает с серым (динамическим) IP.
